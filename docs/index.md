# Руководство TailPrint

Печать документов на принтерах своей сети Tailscale. На компьютере с принтером работает агент. На телефоне, планшете или другом компьютере пользователь открывает веб-интерфейс, выбирает принтер и отправляет файл. Центральный сервер и публичный домен не требуются.

## Где работает

| Устройство | Что установить |
| --- | --- |
| Linux с принтером | Tailscale, Python 3.10+, системные очереди CUPS и утилиты `lp`, `lpstat`. В Debian/Ubuntu они входят в пакет `cups-client`. |
| macOS с принтером | Tailscale и Python 3.10+. Добавьте принтер в системных настройках и убедитесь, что он виден в `lpstat -v`. |
| Windows с принтером | Tailscale, Python 3.10+, Windows PowerShell с `Get-Printer` и SumatraPDF для отправки в драйвер. |
| iOS, Android, Linux, macOS, Windows для отправки | Tailscale и браузер. На настольном компьютере можно также запустить свой агент для просмотра каталога. |

Для печати **Word и Excel** установите LibreOffice на компьютере, к которому подключён принтер. Для PDF и изображений достаточно пакетов приложения и системного средства печати. Агент автоматически ищет LibreOffice и SumatraPDF в стандартных каталогах. Для нестандартной установки добавьте каталог LibreOffice в PATH или передайте `--sumatra "C:\путь\SumatraPDF.exe"`.

## Первый запуск

1. Подключите устройства к своей сети Tailscale. На компьютере с принтером проверьте `tailscale status` и напечатайте системную пробную страницу. Агент использует установленные в ОС драйверы.
2. Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте терминал в каталоге с `requirements.txt`.
3. Создайте окружение, установите зависимости и запустите агент.

**Linux и macOS**

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m tailprint
```

**Windows PowerShell**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m tailprint
```

4. На самом компьютере откройте **http://127.0.0.1:8787**. Во вкладке **Принтеры узла** нажмите **Найти принтеры**, затем **Опубликовать** у нужной очереди. USB, последовательные и параллельные порты помечены по типу подключения. Другие установленные очереди также можно выбрать вручную. Для удаления из каталога нажмите **Снять публикацию**.
5. На втором устройстве с включённым Tailscale откройте **адрес для других устройств**, показанный во вкладке управления и в терминале. Выберите принтер, документ и параметры, затем нажмите **Отправить на печать**. Компьютер с принтером и агент должны оставаться включёнными.

Для просмотра интерфейса до подключения оборудования замените команду запуска на `python -m tailprint --demo`, используя Python из созданного окружения. В этом режиме интерфейс открывается на localhost, работает подготовка документов и демонстрационная очередь. Состояние демонстрации удаляется при выходе. Для остановки нажмите Ctrl+C.

## Документы и раскладка

| Параметр | Возможности |
| --- | --- |
| Файлы | PDF, Word (.doc, .docx), Excel (.xls, .xlsx), JPEG, PNG, SVG. До 25 МиБ на задание. |
| Бумага и ориентация | A4, A3, Letter, книжная и альбомная. Поддержка формата бумаги зависит от принтера и лотка. |
| Масштаб | Вписать в доступную область, только уменьшать, 100 %. При 100 % выходящие за область края обрезаются. |
| Страницы и копии | Весь документ или диапазон вида `1-3,5`. От 1 до 20 копий. |
| Размещение | 1, 2, 4, 6 или 9 страниц на стороне листа. Поля по 5 мм вокруг каждой ячейки. |
| Двусторонняя печать | Односторонняя, переворот по длинному или короткому краю. |
| Брошюра | Две страницы на стороне альбомного листа, автоматическая перестановка и пустые страницы до числа, кратного четырём. Требуется автоматический дуплекс с переворотом по короткому краю. |

LibreOffice использует области печати и разрывы страниц, сохранённые в книге Excel. Диапазон относится к страницам после конвертации. Шрифты документа должны быть установлены на узле печати для точного воспроизведения. Изображения учитывают EXIF-ориентацию. Поддерживаются автономные векторные SVG с текстом и фигурами. SVG со скриптами, внешними ссылками и встроенными растровыми изображениями отклоняются. Защищённые паролем документы предварительно разблокируйте.

## Обнаружение, доступ и история

Агент получает список устройств из локального `tailscale status --json` и периодически запрашивает каталог TailPrint у доступных узлов. Обновление начинается каждые 20 секунд после окончания предыдущего опроса. Устройства без агента могут отправлять документы через браузер. Принтеры появляются в каталоге после публикации. Статус узла показывает доступность агента, состояние бумаги и тонера проверяется на принтере.

Выбор удалённого принтера открывает интерфейс его узла. Браузер отправляет документ напрямую. Правила доступа Tailscale и локальный сетевой экран должны разрешать пользователям TCP-порт 8787 на нужных узлах. Для взаимного обнаружения разрешите этот порт между агентами. При использовании `--port` задайте один номер на всех агентах. Доступ к получению и печати документов предоставляйте доверенным устройствам. Запускайте агент от обычного пользователя с доступом к нужным принтерам.

Публикация доступна только через локальный интерфейс. Другие устройства обращаются к слушателю на IP Tailscale. Предполагается обычное подключение Tailscale с сетевым интерфейсом ОС. Локальный порт управления предназначен для прямого доступа с компьютера. Подключать к нему прокси, Tailscale Serve или Funnel не следует.

В разделе **Мои задания** отображаются последние 60 отправок с текущего устройства на открытом узле. «В системной очереди» означает, что ОС приняла задание. Физический выход листа проверяется на принтере. Если агент остановился при передаче, статус предложит проверить системную очередь перед повтором. Ещё не начатые задания возобновляются после запуска. Повтор того же запроса при обрыве связи использует идентификатор задания и сохраняет одну запись.

Регистрация, очередь и история хранятся в SQLite в `~/.tailprint` (Windows — в профиле пользователя). Путь меняется через `--data-dir`. Исходный файл хранится до окончания обработки, затем содержимое удаляется из записи. Временные файлы удаляются после обработки, остатки прерванного задания очищаются при старте. Имена документов остаются в локальной истории. Очередь ОС управляет собственными копиями.

## Проверка установки

- **Пустой список.** Откройте локальный адрес управления на компьютере с принтером. Проверьте системную очередь, её публикацию, работу агента и Tailscale. Дождитесь обновления каталога.
- **С телефона открывается каталог, но не выбранный принтер.** Проверьте доступ с телефона непосредственно к адресу второго узла и правила для TCP-порта.
- **Ошибка подготовки Word или Excel.** Проверьте установку LibreOffice и возможность открыть исходный файл без пароля.
- **Дуплекс или бумага отличаются от выбора.** Проверьте возможности драйвера, настройки лотка и поддержку автоматического дуплекса.
